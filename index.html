hotswap

Gov0.1.0

Replace Go functions, methods and variables at run time, in tests. Works natively on Apple silicon.

A clean-room, Apache-2.0 replacement for bou.ke/monkey, so tests no longer need to run as GOARCH=amd64 under Rosetta.

  • Patch functions and methods with Patch, PatchT or PatchMethod.
  • Stub return values with Return and ReturnSeq.
  • Spy on calls with NewSpy.
  • Override variables with SetVar.
  • Group patches with NewPatchesT(t), undone when the test ends.
linux · darwinamd64 · arm64Apache-2.0
Source Docs Release notes

Install

$ go get github.com/code-alchemica/hotswap

Use

hotswap.PatchT(t, time.Now, func() time.Time {
	return time.Date(2026, 8, 17, 9, 0, 0, 0, time.UTC)
})
// Every caller of time.Now, in any package,
// now gets that date until the test ends.

Stub

hotswap.Return((*UserRepo).Find, nil, sql.ErrNoRows)

Spy

spy := hotswap.NewSpy(mailer.Send, nil)
defer spy.Unpatch()

signUp("ana@example.com")
spy.Count() // 1
